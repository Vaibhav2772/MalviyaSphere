# MalviyaSphere
### What is MalviyaSphere
MalviyaSphere is an ongoing project that aims to create a social platform on a college level for people to find other people based on their unique interests/niches, comes with a lot of features currently in development.


## Tech Stack
- Framework: React.js
- Styling: CSS

## Project Status
- Homepage / Landing Page
    - Navigation bar with logo, Home, Explore, Teams, Messages, Profile
    - Hero section explaining the platform.
    - Call-to-action buttons: “Find Your People” and “Explore Interests”.
    - Featured hobbies, niches, and technologies.
    - How-it-works section: Discover → Connect → Collaborate.
    - Footer with About, Contact, Privacy Policy, and Terms.
- Authentication
    - Login page with email, password, and “Continue with Google” option.
    - Sign Up page with name, email, and password.
    - Forgot Password page.
    - User profile with editable fields and profile picture upload.
- Interest onboarding
    - Basic Information
    - Select Interests and niches
    - Skill and Experience
    - Goals and Preferences
- Student Profile Page
    - Profile picture, name, bio, department, and year.
    - Selected hobbies, niches, and technical interests.
    - Projects, portfolio links, achievements, and experience.
    - Collaboration goals and preferred roles.
    - Edit Profile, Connect, and Message actions.
    - Separate sections for self-reported skills and verified achievements.
- Teams 
    - Team details
    - Team chat
    - Team members
- Messages
    - Messages between two users.
    - Messages with team members.
